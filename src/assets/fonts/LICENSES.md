# Bundled fonts

Both fonts are bundled locally (no CDN at runtime) and licensed under the
SIL Open Font License 1.1. The full license text sits next to each font.

| Font | Use | Files | License | Source |
|---|---|---|---|---|
| Russo One (Jovanny Lemonad) | Display: titles, buttons, HUD labels | `russo-one/*.woff2` | OFL-1.1, `russo-one/OFL.txt` | Google Fonts via `@fontsource/russo-one` 5.3.0 |
| Exo 2 (The Exo 2 Project Authors), variable weight | UI text | `exo-2/*.woff2` | OFL-1.1, `exo-2/OFL.txt` | Google Fonts via `@fontsource-variable/exo-2` 5.3.0 |

Only the Latin and Latin Extended subsets are included.
