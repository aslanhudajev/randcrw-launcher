## v0.1.0-alpha

The first test release of the ReRAC launcher. The launcher sets up ReRAC, the native rewrite of Ratchet & Clank (2002), from your own disc: point it at an image of your NTSC-U disc (SCUS-97199), and it checks the disc, copies the game data once and starts the game with one click. From the game screen you can also export the game's textures, sounds, models and levels, or extract the data again if something went wrong. Game versions will be downloadable from the launcher as they are released, and mod support comes later.

This is an early alpha, so expect rough edges. The macOS app is not signed yet, so macOS blocks it the first time you open it: go to System Settings → Privacy & Security and choose Open Anyway. The launcher contains no game files; you need your own copy of the game.
